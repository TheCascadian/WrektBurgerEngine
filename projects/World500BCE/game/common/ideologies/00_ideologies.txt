# Ideologies of the 500 BCE world (politics feature). Keys keep their old names (democratic, neutrality, fascist, communist) so laws, AI profiles and history keep working;
# here they stand for: democratic = citizen assemblies, neutrality = crown and temple (royalists), fascist = warrior bands, communist = levelers (commoners against the rich).
# Ideologies with an unlock block do not exist until it is met, and then appear in every country:
#   unlock = { year = -221 }  from that year    unlock = { technology = key }  once any country knows it    unlock = { }  only by script (unlock_ideology = key)
#   unlock = { popularity = 0.05 }  share of each country that follows it the day it appears (default 0.03)
#   chamber = { a b }  chamber_seats = 30  while it rules only these currents sit (a council of nobles, estates); the rest are shut out and become movements
#   assembly = yes  the country has a council or assembly (parliament and parties are shown) even without elections
# Ideologies (politics feature). Every country has a popularity for each of them; the ruling party has one ideology.
#   color          map color (Ideology map mode) and party color
#   adjective      used for rebel countries ("Nationalist Spain") and texts
#   party_name     default party name (countries can rename it: history/politics or set_party_name)
#   elections      countries ruled by this ideology hold elections
#   extremist      gains popularity when stability is low or a war goes badly
#   country_color_blend  { color = { r g b } amount = 0.45 }: the map color of countries ruled by it, unless the country has its own (country_colors)
#   weak_democracy_drift  popularity it gains a month where elections are held but stability or support for the government is low
#   coalition      parties it will govern with (both sides must list each other)
#   opinion        opinion its rulers have of countries ruled by each ideology
#   modifier       modifiers for countries ruled by it (any modifier key: manpower, production, political_power_gain...)
#   government     optional: the country's government word when this ideology takes power
# Scripts: ruling_ideology = fascist, in_government = democratic, popularity_communist >= 0.3, seats_democratic > 50,
#          add_popularity = { ideology = fascist value = 0.05 }, set_ruling_party = communist
