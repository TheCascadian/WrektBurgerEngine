# Laws (laws feature). Each top-level block is a law group; a country has exactly one law of every group.
#   default          the law countries start with (else the first) - governments can set others
#   cost             political power to enact (default: define law_cost, 100)
#   potential        shown only while true      allow   can be enacted only while true
#   unlock           on a group or a single law: it does not exist until unlocked.
#                    unlock = { year = 1450 }  from that year    unlock = { technology = key }  once any country knows it
#                    unlock = { }  only by script (unlock_law = key), checked with law_unlocked = key.
#                    A locked group keeps its default law, so give it a default that does nothing.
#   modifier         modifiers while in force   on_enact effects when enacted
#                    (military service laws: recruitable = 0.015 raises the share of the people that can be called up, 3% + this, 1-5%: raising_troops feature)
#   bans             parties of these ideologies get no seats and cannot govern
#   single_party     only the ruling party is allowed (and there are no elections)
#   suspends_elections  no elections while in force
#   ai_will_do       how much the AI wants it (it changes when another law is clearly better)
# Scripts: has_law = war_economy, set_law = war_economy (free, ignores requirements)
# The laws of the 500 BCE world: what a city, a king or a tribe could decide then. Later laws appear with their age.
