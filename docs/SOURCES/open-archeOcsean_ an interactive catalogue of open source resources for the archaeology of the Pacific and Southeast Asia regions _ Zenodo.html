open-archeOcsean: an interactive catalogue of open source resources for the archaeology of the Pacific and Southeast Asia regions

Authors/Creators

  • Sébastien Plutniak1
  • 1. CNRS, CITERES

Description

An interactive curated catalogue of open source resources for the archaeology of the Pacific and Southeast and East Asia regions. Access it online. This catalogue was created in the context of the OCSEAN OCeanic and South East Asian Navigators European scientific project.
