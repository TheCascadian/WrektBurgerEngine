# 500 BCE reference maps

Reference images the owner supplied for the World500BCE scenario. They are used for facts only (which peoples lived where, which polities existed). No geometry is copied: provinces, states and region shapes are drawn on our own grid. Provenance rows are in `tools/map500bce/provenance/sources.csv` (`ref_*`).
