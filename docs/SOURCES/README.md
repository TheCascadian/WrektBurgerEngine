# Sources

Saved copies of the data-source and license pages the map data depends on. Nothing here is
deleted: every page keeps its `_files` folder beside it. Files were only moved into subject folders.

| Folder | Contents |
|---|---|
| `licenses-and-terms/` | Terms of use and license pages (Creative Commons, ODC-By, Art Institute, Smithsonian, Natural Earth, GEBCO, Wikidata, Neotoma, NASA portal) |
| `pollen-and-biomes/` | Fossil pollen datasets and biome reconstructions (Cao, Li, Dugerdil, Figshare palaeoclimate, Copernicus biome paper) |
| `hydrology-and-ocean/` | GRWL river widths, HydroSHEDS tech doc, WOCE surface drifters |
| `archaeology-and-population/` | Historical urban population (NASA), MesoRad, open-archeOcsean |
| `gazetteers-and-names/` | Syriaca.org, Getty vocabularies |
| `reference-papers/` | Standalone PDFs (Scientific Data article 41597_2020_552) |
| `maps-500bce/` | Reference maps for the 500 BCE scenario (peoples and polities), with sources and licenses |
| `technology/` | Technology papers; `pre-columbian-mesoamerica/` holds Lechtman 1985 on metals in Andean culture (weapons and clothing design reference) |
| `screenshots/` | Screenshots |
| `doc.md` | Working source notes |
